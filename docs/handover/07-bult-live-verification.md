## Настоящая генерация и качество

Контрольный вопрос: «Проверка 13 октября 2026: покажи три наиболее важные проблемы этого проекта и кратко объясни, что проверить первым. Только прочитай результаты, проверки и исправления не запускай.»

Во время запроса в журнале llama.cpp появились задачи 1526 и 1558, 23:16:04–23:16:52 по Алматы. Первая: 1359 обработанных входных и 21 выходной токен; вторая: 1203 и 182. Сумма счётчиков: 2562 / 203. Время вычислений по двум строкам total time: 47,74905 с. Это счётчики вычисления модели, не измеренный счёт провайдера и не длительность всей цепочки HTTP/очереди.

Перед контрольным запросом был пробный вызов `f34e29cb-79b5-47dc-a690-1aff5e10fc66`, тоже COMPLETED. При вводе через автоматизацию потерялась кириллица, поэтому для оценки качества использован повтор с проверенным текстом. Показатели выше относятся только к контрольному окну журнала, не ко всей сессии.

**Связь работает, но содержательная проверка ответа не пройдена.** Для Docker root модель предложила «проверить происхождение аргумента и использовать безопасный разбор данных» — это рекомендация от другого типа проблемы. Для возможного секрета предложено удаление из кода без явного отзыва/ротации. Полный ответ переписан из интерфейса в JSON-доказательство. Статус COMPLETED подтверждает обработку, а не правильность всех рекомендаций.

## Что остаётся открытым

1. Вызов настоящей модели через новый путь пояснений функции 1 (`LLM_PROVIDER`, `llm_explain.py`). Проверенный старый помощник использует отдельный путь `AI_ENABLED` / `ai_service.py` / `security_agent.py`.
2. Адаптер Bult MCP/API для ресурсов, событий сборки и наблюдения работающего digest отсутствует в текущем коде. Доступ к панели Bult не заменяет такой адаптер. Bult MCP не настроен в текущем Codex, токен Bult в проверенном окружении отсутствует; новый токен не создавался.
3. Развёртывание и приёмка новой ветки на согласованном стенде: миграции, очередь проверок образов, приватное подключение модели и исполнитель Docker-песочницы.
4. Исправление и повторная содержательная проверка рекомендаций старого помощника. Нельзя объявлять правильность модели по одному успешному HTTP/COMPLETED.
5. Фактическое денежное списание за тест не измерялось. Панель существующей модели показывает L, 1 vCPU / 2 GB, $24/месяц. Новые платные ресурсы не создавались.

Таким образом, прежнее общее утверждение «настоящая LLM не проверена» уточняется: существующая Qwen на Bult проверена живым запросом; новый путь LLM функции 1 и интеграция ресурсов Bult остаются непроверенными/нереализованными соответственно.
