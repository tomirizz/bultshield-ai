## Обновление уязвимых зависимостей

| Пакет | Было | Стало | Способ | Закрывает |
|---|---|---|---|---|
| `form-data` | 2.3.3 | 2.5.6 | overrides (вложенная) | CVE-2025-7783, CVE-2026-12143 |
| `qs` | 6.5.5 | 6.16.0 | overrides (вложенная) | CVE-2025-15284, CVE-2026-82417 |

`overrides` - поле в package.json, которое заставляет npm использовать указанную версию вложенной зависимости (той, что подтянул другой пакет).

### Как проверено
Все обновления проверены **вместе** в изолированной песочнице (Docker): установка с `--ignore-scripts`, тесты без сети, сборка образа, запуск без сети и проверка `/health`, затем повторный скан Trivy 0.74.0 (база CVE от 2026-10-13 06:41 UTC). Целевые находки исчезли, новых находок приложения не появилось.

### Что важно знать
- Проверка выполнена на копии проекта. Образ не публиковался: пока образ не пересобран, опубликован и повторно просканирован, **работающее приложение не исправлено**.
- Тесты проекта могут быть неполными: зелёные тесты не доказывают совместимость во всех сценариях.

### Не вошло в этот PR (нужен ручной разбор)
- `request`: ни одну находку нельзя закрыть обновлением
- `tough-cookie`: Тесты, сборка и запуск прошли; все 1 целевых находок исчезли после повторного скана. Образ пересобран локально и не опубликован: приложение в эксплуатации не исправлено. Обновление меняет мажорную версию: перед применением нужен просмотр человеком.
- `uuid`: обновление ломает приложение: Шаг «тесты» завершился с ошибкой после обновления (код 1). Тесты шли без сети и до обновления не запускались: причина может быть и в самих тестах.

### Описание от модели (предположение)
- **Что меняется:** Обновление версий form-data и qs из 2.3.3 до 2.5.6 и из 6.5.5 до 6.16.0
