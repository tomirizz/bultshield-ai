# BultShield — пакет для сдачи функции 1

**Текущий этап — тестовый прототип на учебном приложении, без встраивания в платформу Bult.** Недостающая проверка настоящей LLM и описания PR выполнена: [09 — итоговая приёмка LLM и четыре пункта ментора](09-test-prototype-llm-acceptance.md). Проверенный код app/worker на Bult: `51fdac6`, схема `0013`.

Полный цикл исправления проверен локально в Docker; настоящая Qwen проверена на существующем Bult. Это разные среды проверки, а не заявление о работающей облачной песочнице.
