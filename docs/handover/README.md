# BultShield — пакет для сдачи функции 1

**Полная приёмка первого пункта ТЗ ещё не завершена.** На живом Bult развёрнута ветка `feature/security-agent` (серверная логика `ac769fc`, форма Safari в app `55737bb`, схема `0013`), проверены сканеры, очередь, отчёты и новый путь настоящей Qwen. Не подключены облачная песочница исправлений и адаптер ресурсов/событий Bult. Локальный прототип и облачная интеграция принимаются отдельно.
